# 자음모음팝 타이포그래피

## 역할

- 넥슨 Lv.1 고딕 Bold: 화면·섹션 제목, 주요 행동 버튼, 게임 모드 탭, 게임판 자모와 자판.
- Pretendard Variable: 닉네임, 채팅, 설명, 입력, 설정, 타이머와 인원 등 데이터.
- 제목 안에 포함된 작은 상태 정보는 Pretendard로 유지한다.
- 엑셀·터미널 모드는 기존 전용 글꼴을 유지한다.

`app/typography.css`의 `--font-game`, `--font-body`를 사용한다. 새 컴포넌트에서 별도 폰트 스택을 만들지 않는다. 제목은 Bold 700, 본문은 400–600을 사용하고 넥슨 서체에 가짜 굵기를 생성하지 않는다. 채팅 전체나 닉네임에 게임용 서체를 적용하지 않는다.

기존 반응형 크기와 카드 높이를 보존하는 첫 단계이며 대기실의 정보 구조 변경과는 별도이다. 향후 크기는 제목 24–28px, 버튼 16–18px, 본문 14–16px, 보조 정보 12–13px 범위에서 역할별로 정리한다.

## 배포와 출처

폰트는 `/fonts/`에서 직접 제공한다. 외부 CDN이나 Google Fonts 요청은 발생하지 않는다. `font-display: swap`으로 폰트 다운로드 중에도 입력·읽기를 막지 않는다.

- 넥슨: 공식 ZIP의 전체 Bold OTF를 변환·수정 없이 포함. 저작권 고지는 `public/fonts/Nexon-NOTICE.txt`.
- Pretendard: 공식 저장소 v1.3.9의 Variable WOFF2. SIL OFL 전문은 `public/fonts/Pretendard-LICENSE.txt`.
- 첫 로드 용량은 두 파일 합계 약 2.9MB이며 후속 요청은 브라우저/정적 자산 캐시를 사용한다. 모든 글자를 보존하기 위해 이번 변경에서는 서브셋을 만들지 않는다.

확인 시 `ㅂ ㅏ ㄹ ㅏ ㅁ`, `ㄲ ㅆ ㅘ`, 긴 방 이름, 긴 닉네임, 숫자 `1:00 → 0:59`를 비교한다. 폰트 적용만으로 대비나 정보 위계 문제가 해결된 것으로 간주하지 않는다.
