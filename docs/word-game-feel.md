# 단어 게임 피드백

판정과 입력 로직을 바꾸지 않고 플레이의 반응을 연결한다.

- 입력: 새로 들어온 자모만 180ms 동안 눌림·착지. 완성된 입력 줄은 테두리로 준비 상태 표시.
- 오류: 현재 입력 줄만 흔들고 기존 제출 행은 고정한다. 오류 문구와 입력값 보존은 기존 경로를 사용한다.
- 제출: 기존 즉시 대기 피드백 유지. 연출용 최소 대기나 입력 잠금 없음.
- 판정: 서버 확정 뒤 55ms 간격, 각 타일 280ms. 노랑은 짧은 좌우 반응, 초록은 착지 반응.
- 정답: 마지막 판정 공개 후 타일 축하, 허용된 효과음, 기존 입자 효과 순서. 공통 `judgmentTiming`으로 타이밍 계산.
- 결과: 승리·종료 아이콘과 보상 카드의 짧은 진입 효과. 보상은 서버 결과만 사용.
- 재접속으로 복구된 성공 기록에는 승리 효과음을 재생하지 않는다.
- 엑셀 모드는 타일 애니메이션·판정 덮개를 제거하고 기존 판정색을 유지한다.
- 동작 줄이기 설정에서는 움직임을 제거한다. 소리는 기존 켜기 설정을 따른다.

검증: 로컬 게임방에서 가방 입력→제출→노랑/회색 판정, 풀이 정답 제출→보상, 새로고침 시 연출 재생 없음, 엑셀 판정색/다크 회색, 전체 CI 233 tests 통과. 실제 휴대폰의 촉각·음향 체감은 별도 기기 검증 대상이다. 입력 조합·삭제·서버 채점·보상 저장·운영 DB 구조는 수정하지 않는다.
