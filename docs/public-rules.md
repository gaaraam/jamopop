# 공개 게임 방법 (#19)

`/how-to-play`는 로그인 없이 읽을 수 있는 서버 렌더링 페이지입니다. 실제 `splitWord`와 `score`로 사과→가방, 사과→학교 예제를 생성합니다. 정답 예시는 설명용으로 고정되어 있으며 진행 중인 문제를 조회하지 않습니다.

- 공통 서비스 헤더, 판정 색·표식, 디자인 토큰 재사용
- 자모 분해·중복 개수·모드별 조건 안내
- 공통 하단과 기존 도움말에서 연결
- 오늘의 단어와 첫 판 연습으로 이동 가능
- 홈의 접근 가능한 제목과 설명을 한글 단어 추리 게임으로 정리. 기존 25칸·콩알 캐릭터 유지

검증: 기본 CI, 예제 판정, 로그인 없는 HTML 본문의 규칙/링크, 로컬 브라우저의 밝은/어두운 화면 확인. 실제 휴대폰 검증과 검색 색인·OG·사이트맵은 포함하지 않으며 #18/#20에서 별도로 진행합니다.

DB·계정·플레이 기록 변경 없음. 배포 후 `/how-to-play` 응답과 진입 링크를 확인합니다.
