# 자음모음팝 UI 기준

## 정보 우선순위

대기실의 첫 행동은 방 탐색·입장·생성이다. PC에서는 방 목록을 주 영역으로, 내 프로필·옷장·친구를 280px 보조 영역으로 배치한다. 모바일에서는 방 목록을 먼저 보여주고 보조 정보를 그 아래로 이동한다. 채팅은 기존 하단 도크 하나를 사용한다.

## 시각 토큰

`app/design-system.css`의 `--ui-*`를 사용한다. 대기실에 이어 `app/room-system.css`에서 게임방 패널·헤더와 공통 모달에 적용한다. 게임판 판정색, 자판 크기, 캐릭터 보상 효과는 기존 규칙을 유지한다.

| 항목 | 기준 |
| --- | --- |
| 간격 | 4 / 8 / 12 / 16 / 24 / 32px |
| 카드 | 20px 모서리, 1px 경계, 약한 그림자 |
| 입력·버튼 | 12px 모서리, 기본 44px 높이 |
| 제목 | 넥슨 Lv.1 고딕, 페이지 28px / 카드 19px |
| 본문·닉네임 | Pretendard, 13–16px |
| 부가 정보 | 11–12px, 대비를 확보한 보조색 |
| 강조색 | 노랑은 주 행동, 판정 초록·노랑·회색은 게임 의미 유지 |
| 키보드 포커스 | 3px 외곽선, hover 없이도 식별 가능 |

배경의 기존 글래스 분위기는 유지한다. 카드마다 별도 그라데이션과 깊은 그림자를 중복하지 않는다. 카드 안의 부가 정보는 경계선·정렬·간격으로 구분하며 작은 카드 속에 작은 카드를 반복하지 않는다.

## 대기실 컴포넌트

- 상단: 중복 GNB를 없애고 대기실 제목, 방 개수, 개인 도전, 방 만들기, 테마·도움말을 한 줄로 통합. 개인 도전과 방 만들기는 PC 136×44px로 동일하게 맞추고 색으로만 강조를 구분.
- 방 카드: 이름과 더보기 → 모드·진행 상태 → 캐릭터·진행 점 → 인원·입장. 관전과 관리 기능은 더보기에 유지.
- 계정: 캐릭터·닉네임·레벨·경험치, 옷장·계정 연결·운영 진입.
- 친구: 기존 최근/친구 탭, 요청 수락·거절·합류 기능 유지. 독립 타일 대신 구분선 목록 사용.
- 하단 채팅: 기존 열기/닫기와 백틱 단축키 유지. 상단 최근 메시지 배너는 중복 진입점이므로 제거.

## 확장 원칙

새 기능을 추가할 때 우선 어느 영역의 행동인지 정한다. 설명문과 배지, 버튼을 모두 상시 노출하지 않는다. 기능 설명은 도움말·툴팁에, 상태는 짧은 라벨에, 행동은 버튼에 둔다. 색만으로 상태를 전달하지 않는다.

밝은/어두운 테마, 390px·태블릿·데스크톱, 긴 방 이름, 빈 목록, 검색 결과 없음, 게스트/회원/관리자 상태를 확인한다. 운영 데이터와 게임 판정은 디자인 변경에 포함하지 않는다.

## 게임방과 모달

- 게임방 헤더는 방 이름과 방 이동, 오른쪽 도구를 한 줄에 두고 대기실처럼 경계선으로 구분한다.
- 게임판·참가자·순위는 같은 카드 표면과 20px 모서리를 사용한다. 보조 컨트롤은 12px 모서리의 약한 표면으로 구분한다.
- 작은 데스크톱의 엑셀 모드에는 게임방 스타일을 적용하지 않는다. 모바일 게임판과 입력 영역의 크기·배치는 기존 스타일이 담당한다.
- 공통 모달은 제목 22px, 본문 13–16px, 패딩 24px, 주요 버튼 최소 높이 44px를 사용한다. 작은 화면에서는 패딩 20px, 제목 20px로 줄인다.
- 모달은 화면 높이를 넘기지 않고 내부 스크롤한다. 키보드 포커스와 Escape 닫기는 기존 Radix 동작을 유지한다.
- 도움말은 판정색과 자모 설명을 먼저 보여주고 진행·순위와 단어 사전 설명은 펼쳐 본다.

## 상점과 개인 도전

- 대기실 복귀·페이지 제목·보유 골드/테마를 경계선 헤더로 정렬한다. 제목은 PC 28px, 모바일 22px.
- 상점은 선택한 스킨 미리보기와 카탈로그로 구분한다. 선택은 포커스색 테두리, 소유/장착은 텍스트 배지로 표시한다. 모바일 카탈로그는 2열로 이름과 캐릭터 크기를 확보한다.
- 구매·장착은 44px 노란 주 행동을 사용하며 구매 확인과 해금 조건은 기존 동작을 유지한다.
- 개인 도전은 콩알 아파트의 층을 선택하는 공간형 지도를 사용한다. 층마다 콩알 친구와 세 개의 창으로 진행을 표현하고, 선택한 층에서만 이야기와 세 단계를 보여준다. 잠긴 층도 둘러볼 수 있지만 도전 잠금은 유지한다. 상세·플레이 패널은 공통 20px 모서리와 표면 토큰을 사용한다.
- 각 페이지 스타일은 공통 --ui-* 토큰을 참조한다. 게임 타일과 자판 판정색, 제한시간·보상·저장 로직은 변경하지 않는다.

개인 도전 풀이 화면은 게임방과 같은 정사각 타일·판정색·자판을 사용하고 입력창 → 자판 → 전체 폭 제출 순서로 둔다. 전체 성장 수치는 지도에서만 표시하고 풀이 중에는 층·시간·남은 기회를 표시한다. 이야기는 접어서 열람한다.

## 콩알 아파트 보상

1층(1–3단계), 3층까지(1–9단계), 전체(1–15단계), 전 단계 별 3개를 달성하면 전용 스킨을 해금한다. 회원의 서버 저장 최고 기록으로 계산하므로 기존 달성자도 포함된다. 골드 차감·중복 구매·데이터 마이그레이션은 없다. 게스트 달성 기록은 기존 브라우저 범위이며 회원 자동 이전을 약속하지 않는다.

보상은 상점에서 구매할 수 없고 달성한 계정만 장착한다. 도전 보상 캐릭터는 기본 레벨 제한과 별개로 장착할 수 있다. 재도전의 이야기는 기본 접힘, 처음 도전은 첫 입력 전 짧은 대사, 층 완료에는 친구의 감사 반응을 사용한다. 45별은 특별 엔딩과 황금별 구조대 스킨으로 표현한다.

## 판정 접근성

실제 제출된 타일과 자판에는 색과 함께 ✓(위치 일치), •(다른 위치), −(미포함 또는 개수 초과)를 표시합니다. 입력 중이거나 빈칸에는 표식을 넣지 않습니다. 화면 읽기 도구에는 자모와 판정 이름을 함께 제공하고 장식 표식은 중복해서 읽지 않습니다. 개인 도전 자판을 Enter/Space로 누르면 해당 버튼의 포커스를 유지합니다. 터치 자판은 높이 최소 44px를 유지하며, 작은 화면에서 너비는 자모 배열을 유지합니다. 시스템의 모션 줄이기 설정에서는 게임판·키 입력 모션을 끕니다.
