# 회원 이용 범위

- 게스트: 개인 도전·오늘의 단어만 플레이. 방·회원·채팅·초대·친구 조회와 참여 불가.
- Google 회원: 로그인 즉시 방과 커뮤니티를 포함한 모든 기능 이용. 관리자 가입 승인은 없다.

## 구현 경계

Worker가 검증된 Google 세션으로 회원 여부를 판정한다. 클라이언트가 보낸 신원 헤더는 Worker에서 제거한다. Worker의 개인 API 허용 목록(`build/member-access.mjs`) 밖의 요청은 게스트에게 403, 방 링크·관리자 페이지는 개인 게임 화면(`/personal`)으로 안내한다. 화면의 버튼 숨김에 의존하지 않는다. 새 API를 추가하면 공개 범위를 이 목록과 함께 검토한다. 기존 신고·이용 제한은 계속 적용한다.

## 이력

#79에서 도입한 관리자 가입 승인은 해제했다. 운영 D1의 `0034_member_approval.sql` 열(`approval_status` 등)은 롤백하지 않고 남겨 두며 코드에서 읽지 않는다. 새 SQL 적용은 필요 없다.
