# 플레이 접근성 점검 (#18)

## 이번 변경

- 공통 게임판/자판과 개인 도전에 색 외 판정 표식(✓ / • / −) 제공.
- 자판과 개인 도전 타일에 자모·판정 이름을 제공. 표식은 중복 낭독하지 않음.
- 개인 도전 자판의 Enter/Space 활성화는 버튼 포커스를 유지. 마우스 클릭은 기존 입력 복귀 유지.
- 입력/자판/결과 행동의 키보드 포커스 표시, 터치 자판 최소 높이 44px, 모션 줄이기 적용.
- 서버 판정·저장·보상·DB 변경 없음.

## 확인한 범위

로컬 브라우저에서 밝은/어두운 테마의 오늘의 단어 결과에 모든 판정 표식을 확인했습니다. 개인 도전 시작 후 자판 버튼을 Enter로 활성화하면 자모가 1회 입력되고 버튼에 포커스가 유지되는 것을 접근성 트리에서 확인했습니다. 테스트와 빌드 결과는 PR에 기록합니다.

## 남은 검증 (이슈 전체 완료로 처리하지 않음)

- 실제 iOS Safari/Android Chrome의 5·6·7칸, 일반/아이템/스피드/개인 도전 완주.
- 실제 IME 조합, 채팅 전환, 외장 키보드, 화면 읽기 도구 검증.
- 작은 화면/엑셀 모드의 표식과 자모 간격, 느린 연결, 제출 버튼 가림 확인.
- 대비 수치와 시스템 모션 줄이기 설정을 켠 기기의 실제 효과 확인.

브라우저 레이아웃 검증을 실제 휴대폰 검증으로 보고하지 않습니다.
