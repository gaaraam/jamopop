# 자모 톡톡

`/solo/toktok`는 합성 자모의 구성 관계로 판 전체의 연쇄를 만드는 5×5 개인 퍼즐입니다. 기존 시안 ‘연쇄 팝’을 정식 개인 도전에 통합했습니다. 자모 정리·증폭 합체는 이번 범위에 포함하지 않습니다.

- 붙어 있는 같은 자모 2개 이상을 누르면 제거합니다. 1라운드에서는 18번 안에 18,000점에 도전합니다. 이후 목표가 2,000점씩 올라가며 7라운드부터는 30,000점으로 유지됩니다. 실패하거나 새 판을 열어도 현재 라운드를 유지합니다.
- ㄲ → ㄱ, ㅘ → ㅗ·ㅏ, ㅐ → ㅏ·ㅣ를 판 전체에서 연결하며 구성 자모를 공유하는 다른 합성 자모도 발동합니다.
- ㄱ 4개 이상 → ㄲ. ㅏ 4개 이상 + 판의 ㅗ 1개 → ㅘ. ㅣ 4개 이상 + 판의 ㅏ 1개 → ㅐ. 수량은 게임의 합성 임계값이며 실제 한글 조합 개수를 뜻하지 않습니다.
- 제거 칸 수² × 20 + 발동한 합성 자모 수 × 500점. 재배치는 시드 기반이며 같은 이동 기록은 항상 같은 결과를 냅니다.
- 목표 달성 또는 18회 소진으로 종료합니다. 되돌리기, 새 판, 최고 점수, 한 수 힌트를 제공합니다. 힌트는 즉시 점수가 가장 큰 합법적 수이며 전체 최적해를 보장하지 않습니다.

## 피버와 라운드

- 4~6개 기본 자모 무리 +1칸, 7개 이상 +2칸. 합성에 성공하면 추가 +1칸, 합성 자모 발동마다 +1칸(한 수에 최대 +3칸)을 쌓습니다. 게이지 최대는 6칸입니다.
- 가득 찼다면 **다음 유효한 폭발의 점수 전체를 2배**로 적용하고 게이지를 비웁니다. 피버 사용 수에는 재충전하지 않습니다. 무효 입력은 피버나 남은 횟수를 소모하지 않습니다. 시간제한 없이 큰 수를 선택할 수 있습니다.
- 새 규칙의 시작판은 시드별로 기본 자모와 합성 자모 위치가 달라집니다. 보통 자모 한 쌍과 합성 자모 세 개를 포함합니다. 옛 판은 기존 고정 준비 배치를 보존합니다.
- 결과에 실제 최대 연쇄·피버 사용 횟수를 표시합니다. 목표 달성 후 ‘다음 라운드’에서만 라운드를 올립니다. 되돌리기는 피버/점수/횟수를 이동 재생으로 함께 복원합니다.

## 저장과 안전

`jamopop-toktok-v2` 키의 저장 형식 v2에 초기 시드·이동 기록·규칙 버전·현재/최고 라운드·최고 점수를 저장합니다. 새 저장이 없으면 `jamopop-toktok-v1`에서 가져오며 원본 키를 수정·삭제하지 않습니다. 기존 v1의 진행 중인 판은 원래 규칙과 배치로 재생하며 새 판부터 v2 규칙을 적용합니다. 저장 데이터를 읽을 때 엔진으로 이동 기록을 다시 검증합니다. 변조·손상 기록은 새 판으로 복구하며 저장 실패를 화면에 안내합니다. 현재 판은 새로고침과 페이지 복귀 때 복원합니다. 개인 도전의 최근 게임 링크에도 포함합니다.

다른 개인 퍼즐과 마찬가지로 브라우저 한정 기록입니다. 로그인 계정 기록·XP·골드·순위에 쓰지 않으며 DB/API/인증 변경과 마이그레이션이 없습니다. 향후 계정 보상 도입은 서버 재연산·중복 방지와 별도로 설계해야 합니다.

## UI와 검증

기존 ServiceHeader·콩알 캐릭터·글꼴·표면 토큰을 재사용합니다. 타일은 버튼이며 Enter/Space와 방향키로 조작합니다. 물리 한글 입력을 전역으로 가로채지 않습니다. 첫 복귀에는 폭발을 재생하지 않으며, 탭 숨김·모션 줄이기 변경·언마운트 시 효과를 종료합니다. 효과음은 Web Audio를 사용자 입력 시 시작하며 끌 수 있습니다. 렌더링·입력에 서버 조회나 무거운 3D 엔진을 추가하지 않습니다.
