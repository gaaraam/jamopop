# 검색·공유 운영 (#20, #34)

현재 정규 주소는 https://play.jamopop.workers.dev 입니다. 홈·오늘의 단어·게임 방법만 사이트맵에 포함합니다. Worker는 쿼리 없는 해당 세 경로의 정상 응답에만 index를 허용하며 그 외에는 `X-Robots-Tag: noindex, follow`를 보냅니다. 인증 및 접근 권한 검사는 기존대로 별도 유지합니다.

robots.txt는 크롤링을 차단하지 않습니다. 차단하면 검색 로봇이 noindex를 읽지 못할 수 있기 때문입니다. 정적 이미지·폰트는 공개 자산입니다. 개인정보·약관·문의는 열람 가능하지만 색인 대상에는 포함하지 않습니다.

공개 페이지마다 제목·설명·canonical·OG/Twitter 메타를 제공합니다. 1200×630 PNG는 기존 콩알 자산과 예시 25칸으로 구성되며 실제 정답·사용자 데이터가 없습니다.

오늘의 단어 결과는 기존 `dailyShare`가 생성하는 익명 격자 텍스트만 공유합니다. 시스템 공유 지원 시 공유창, 미지원/오류 시 복사, 복사 실패 시 선택 가능한 텍스트를 제공합니다. 공유 취소는 오류나 복사로 처리하지 않습니다. 별도 복사 버튼도 유지합니다. 진행 중인 문제는 공유하지 않습니다.

## 후속 운영 확인

- 정식 도메인은 미결정. 변경 시 canonical·사이트맵·robots·공유 주소·Google 반환 주소 및 기존 세션 영향을 함께 변경합니다.
- Google Search Console/네이버 서치어드바이저 소유권 확인 및 사이트맵 제출은 아직 진행하지 않았습니다.
- 실제 카카오톡 등 서비스의 미리보기 캐시 갱신, iOS/Android 시스템 공유창은 실제 기기에서 확인해야 합니다.
- 검색 노출·색인·공유 전환 효과는 보장하지 않습니다. #20 전체는 위 운영 확인이 끝날 때까지 열린 상태로 유지합니다.

DB 마이그레이션 없음. 롤백은 코드 이전 버전 배포이며 기존 기록에 영향이 없습니다.
