기존 데이터 일괄 정리·실사용자 시험 구매·삭제는 실행하지 않았다. OAuth 로그인 과정의 정상 세션 발급·로그인 시각 갱신은 발생한다. 이번 PR은 테스트·문서만 변경하며 마이그레이션이 없다.

초기 관찰 목표는 동시 플레이 약 10명이며 보장 수용량/자동 정원이 아니다. 무료 요청·D1 한도와 운영 중단 기준을 준수한다. 실제 모바일 완주·대규모 무중단·법률 준수를 검증 완료라고 안내하지 않는다.
