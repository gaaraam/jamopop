## 기존 기록 보존

운영 배포 전후 DB를 비공개 백업으로 비교해 원래 53개 사용자 테이블의 전체 행 내용·건수가 동일함을 확인했다. 계정·게임·골드·XP·스킨·가구의 실제 삭제/수정은 실행하지 않았다. 신규 스키마 마이그레이션은 필요하지 않았다. 앞으로 동작하는 Cron은 만료된 로그인 세션·삭제 미리보기·조회 코드·요청 제한 카운터만 종류별 최대 500건 처리하고 유효 세션·게임·재화·삭제 감사는 제외한다.

원격 복구/롤백은 운영과 분리한 가상 데이터 환경에서만 실행했다. 실제 사용자 원문, 인증키, 백업 SQL, 원본 요청 추적 로그는 공개 저장소에 넣지 않는다.

## 검증의 한계

- 원격 100명 시험은 한 번의 합성 부하이며 안정적 100명 수용 보장이 아니다. 제출 p95 2727ms, 진행판 p95 5288ms로 아직 느리다. 최초 입장 중 503 한 건은 원인이 확인되지 않았다.
- 작은 화면의 CSS viewport 관찰·HTTP 시나리오는 실제 휴대폰 입력·접근성 도구 검증을 대신하지 않는다.
- Google 동의 화면은 외부/테스트 상태다. 공개 게시가 끝났다고 안내하지 않는다.
- 콘텐츠 보관 정리는 미리보기만 제공하며 이번 배포에서 원문을 지우지 않는다.
- P0 #14·#15는 닫혔지만 #16·#17·#18은 위 인수 항목이 남아 열어 둔다.
