# 콩알이의 집: 생활·방문·프로필

## 화면 체계
- 대기실, 개인 도전, 캐릭터/가구 상점, 내 집은 ServiceHeader를 공유합니다. 기존 제목 왼쪽·행동 오른쪽·하단 구분선 구성을 유지합니다.
- 집은 고정 1.6:1 좌표계입니다. PC와 모바일에서 가구 배치 좌표는 동일하며 화면 배율만 변합니다.
- 상시 사이드 패널/방문 목록 대신 방 안 캐릭터, 친밀도 버튼과 하단 도구를 우선합니다. 친구와 선물은 눌러서 엽니다.
- 프로필: 요약(캐릭터, 레벨, 완료 판, 성공, 성공률, 평균 시도), 플레이 기록, 꾸미기, 계정 설정. 이메일과 문의 ID는 설정에만 표시합니다. 기존 모달 클래스의 560px 폭 제한을 제거했습니다.

## 생활 규칙
- 화면 안에서 걷기/쉬기/졸기, 가구 근처에서 구경/휴식, 누르기/간식/놀이 반응. 좌표 이동은 클라이언트 전용이며 서버 폴링을 추가하지 않습니다.
- 쓰다듬기·간식·놀이 각각 한국 날짜 기준 1점, 친구 방문 인사 1점: 하루 최대 4점. 같은 날 재시도/다중 탭 요청은 DB 기본키로 중복 적립을 방지합니다. 미접속 감점 없음.
- 12/36/72 친밀도에서 보상 스킨이 해금됩니다. 상점에서 장착할 수 있고 골드 구매는 불가합니다.
- 수락한 친구 관계만 방문 가능. 방문 인사는 친구 집당 하루 한 번이며 방문 보상은 전체 친구 합산 하루 한 번입니다. 공개 응답에는 이메일/계정 ID/기록이 없습니다.
- 방문 화면은 친구의 저장된 집을 보는 비동기 방문입니다. 실제 동시 접속이나 실시간 합방을 의미하지 않습니다.
- 모션 줄이기 및 백그라운드 화면에서는 자율 이동을 줄이고, 배치 중에는 이동을 멈춥니다.

- 기존 집/골드/게임 기록 테이블 수정이나 삭제 없음.
- 2026-10-17 운영 D1에 0027을 적용하고 신규 테이블 2개 및 인덱스 1개를 확인했습니다. deploy-schema.json에 적용 파일 SHA256을 등록했습니다.
- 적용 전후 rooms 8, plays 1013, members 68, profiles 14, kongal_homes 0, skin_purchases 0으로 동일했습니다. 기존 데이터 수정/삭제는 실행하지 않았습니다.

## 검증
- SQLite 기반 실제 API 테스트: 인증/타 출처 요청 차단, 돌보기 다중 요청, 날짜 경계, 친구 아닌 계정 접근 차단, 타인의 돌보기 차단, 인사 중복 방지, 친구 삭제 후 접근 차단, 친밀도 보상/골드 불변.
- 기존 구매·가구 배치·게임 테스트 포함 전체 CI 실행.
- 브라우저 로컬 테스트는 운영과 분리된 테스트 계정/DB를 사용합니다.

## 친밀도 화면 정리
- 노출 이름을 ‘콩알 친밀도’로 통일합니다. 누적 점수는 유지하고 진행 막대는 다음 선물 구간을 기준으로 표시합니다. 다음 보상 스킨과 남은 친밀도를 집 아래에서 바로 확인합니다.
- 돌봄 성공 응답 후 캐릭터 말풍선과 실제 증가량을 표시합니다. 같은 행동을 다시 누르면 로컬 반응만 재생하고 추가 적립을 표시하지 않습니다. 오늘 완료 표시는 한국 날짜가 같은 응답에만 적용합니다.
- 배치 모드에서는 바닥 격자와 배치 안내를 표시합니다. 변경 없는 완료는 저장 요청을 보내지 않으며 요청 실패 시 배치 초안을 유지합니다. 로딩·돌봄·저장에 요청 시간 제한을 둡니다.
- DB 마이그레이션이나 기존 친밀도·가구 좌표·보상 조건 변경 없음.
- 프로필 요약 상단에 로그인 이메일·계정 전환·로그아웃을 표시합니다. 계정 전환은 기존 Google 계정 선택 OAuth를 이용하고 성공 후 프로필로 돌아옵니다. 게임 프로필 연결/이전과 Google 계정 전환은 다른 동작이며 기록을 병합하거나 덮어쓰지 않습니다.
