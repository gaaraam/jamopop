# 콩알의 집과 이웃 골목

집에서 이동 → 옷장에서 미리보기·착용 → 문 밖 골목 → 친구 집 방문을 연결한 첫 버전이다. 기존 대기실의 빠른 게임 입장은 유지한다.

## 조작과 저장 경계

- 방 바닥을 클릭하거나 터치하면 가구를 피해서 이동한다. 방에 포커스가 있을 때 방향키 또는 WASD를 누르는 동안 연속 이동한다. 대각선 속도를 정규화하고 가구에 닿으면 벽을 따라 미끄러진다. 텍스트 입력과 다른 화면의 키는 가로채지 않는다.
- 이동 좌표는 화면 크기에 독립적인 로컬 상태다. 서버 요청이나 위치 저장은 하지 않는다. 이동할 때만 애니메이션 프레임을 사용하며, 비활성 탭·모달·가구 편집 중에는 중지한다.
- 가구의 기존 좌표·revision 저장 방식은 그대로다. 러그는 통과하고 다른 가구의 발밑은 피한다.
- 옷장 선택은 미리보기다. 착용 버튼으로만 기존 `/api/shop`의 소유권 검사 후 저장한다. 보유하지 않은 옷 구매는 상점에서 한다. 기본 모습은 현재 캐릭터의 스킨 해제다.
- 이웃은 기존의 수락된 친구 관계를 사용한다. 방문 API가 관계를 다시 검사한다. 친구 집은 마지막 저장 모습이며 실시간 동시 접속 공간이 아니다.
- 방문 인사·친밀도는 기존 일일 제한과 보상 로직을 사용한다. 이동이나 방문 화면 열기 자체로 보상을 지급하지 않는다.

## 회귀 검증

1. PC에서 바닥 클릭 및 방향키 길게 누르기, 상하좌우 이동·가구 우회·탭 전환 시 정지·호버 시 좌표 고정, 문 이동 후 골목 열기.
2. 옷장 미리보기만 한 뒤 닫으면 기존 모습 유지. 착용하면 집·새로고침 후 반영.
3. 이웃 집 방문 → 하루 한 번 인사 → 골목 → 내 집 복귀.
4. 390px 화면에서 옷장 스크롤·닫기·착용, 가구 편집 도구와 이동 충돌 없음.
5. 라이트·다크 모드, 동작 줄이기, 모달 키보드 포커스, API 오류 재시도.
6. `tests/home-walk.test.mjs`, 기존 home-life/shop/home 테스트 및 전체 CI.

DB 마이그레이션과 운영 데이터 보정은 필요하지 않다. 향후 공유 공간의 실시간 접속·위치 동기화는 별도로 설계해야 한다.
