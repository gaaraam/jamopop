# 소식·출석·감사 이벤트

- `/news`: 공지, 운영 업데이트, 감사 이벤트와 일일 출석. 로그인·연령 확인 없이 안내성 소식 열람 가능. 게임 진입의 연령 확인은 유지.
- `/admin/news`: 관리자만 초안·게시·비공개와 이벤트 기간/금액을 관리. 게시 전에 미리보기 제공, 이벤트 수령 인원·총 지급 골드 조회.
- 기존 `/admin/announcements` 실시간 배너는 별도 유지한다. 새 게시물을 자동으로 전체 화면에 띄우지 않는다.
- 출석: 한국시간 00:00 기준 하루 1회 50 G. 수령 버튼을 눌러 받는다. 연속 출석을 놓쳤을 때 불이익 없음.
- 이벤트: 1~10,000 G, 최대 90일 수령 기간. 시작 시각 포함, 종료 시각 제외. 초안·비공개·종료 이벤트는 신규 수령 불가.
- Google subject + 보상 종류 + 출석일/이벤트 ID 고유키로 한 번만 지급한다. 연결 프로필을 전환해도 중복 수령 불가. 금액은 수령 당시 선택 프로필에 귀속되며 다른 프로필로 이전하지 않는다.
- 이벤트 적격 판정과 지급은 단일 INSERT SELECT이고 중복 충돌은 무시한다. 이미 받은 요청을 재전송하면 기존 수령 내역을 반환한다.
- 수령자가 생긴 이벤트의 종류·금액은 수정할 수 없다. 비공개 전환해도 지급 내역을 회수하지 않는다.
- 게임 골드 및 기존 구매 내역에 새 보상 원장을 더해 잔액을 계산한다. 방에 참여한 적 없는 신규 회원도 사용 가능하다.
- 계정 삭제 미리보기·실행에 보상 원장도 포함한다. 공개 API에 subject/프로필 ID/이메일은 반환하지 않는다.
- 신규 짧은 폴링 없음. 페이지 진입·복귀·수령·수동 갱신 때 조회한다.

## 배포

`drizzle/0033_news_events.sql`은 추가 전용. 현재 저장된 배너가 있으면 한 건을 소식 보관함으로 복사한다. 과거 배너 이력을 만들어내지 않는다. 게임/사용자/구매 기록 변경 없음.

운영 적용은 복구 지점 확보 → 신규 SQL 적용 → 구조 및 기존 기록 수 확인 → deploy-schema.json 갱신 → 코드 머지/배포 순서. 이 PR만으로 운영 DB가 변경되지 않으며 적용 전 배포 가드를 유지한다. 롤백 시 새 원장을 삭제하지 않는다. 구버전에서는 새 보상 잔액이 표시되지 않으므로 구매 중지 후 복구 버전을 배포한다.
